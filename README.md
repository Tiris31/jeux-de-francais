# Jeux de français

Deux jeux pour s'entraîner en français, dix minutes par soir :

- **Les Briques de l'espace** (5e) : lecture, vocabulaire, grammaire et conjugaison.
- **Brevet City** (3e) : grammaire, connecteurs logiques, subjonctif, dictées et mini-brevet.

Ouvrir `index.html` pour choisir un jeu. La progression est enregistrée automatiquement dans le navigateur ; un code de sauvegarde, dans l'espace parent, permet de la transférer sur un autre appareil.
